# Local Train Playlist 🎵

A modern, web-based music player and playlist application built with Next.js. It allows users to search for songs, manage a playlist, and play music seamlessly using YouTube's playback engine, complete with lyrics integration.

## Features ✨

- **Music Playback**: Integrated YouTube player (`react-youtube`) for seamless audio playback.
- **Search & Discover**: Find songs and playlists effortlessly using `yt-search`.
- **Lyrics Integration**: View song lyrics while listening to your favorite tracks.
- **Modern UI**: A responsive, beautiful, and interactive user interface styled with Tailwind CSS.
- **Playlist Management**: Add, remove, and manage your tracks dynamically.
- **Playback Controls**: Play, pause, skip, and shuffle functionality.

## Tech Stack 🛠️

- **Framework**: [Next.js](https://nextjs.org/) (React 19)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Media & APIs**: `react-youtube`, `yt-search`
- **Language**: TypeScript

## Getting Started 🚀

### Prerequisites

Make sure you have Node.js and npm (or yarn/pnpm) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   cd local-train-playlist
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the app in action.
